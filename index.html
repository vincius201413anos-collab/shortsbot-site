ShortsBot

Desenvolvido com os YouTube API Services · Uses YouTube API Services

O ShortsBot é uma ferramenta pessoal e privada que cria vídeos curtos educativos e originais e os publica no canal do próprio dono, Curioso ao Máximo no YouTube, pelas APIs oficiais. Ela não é oferecida a outras pessoas e só acessa a conta que o próprio dono autorizou.

O que a ferramenta faz com o YouTube

  • Envia os vídeos produzidos para o canal do dono (YouTube Data API v3, videos.insert).
  • Lê as estatísticas do próprio canal para aprender quais formatos funcionam melhor (YouTube Analytics API).
  • Lê a lista pública de vídeos em alta no Brasil para escolher temas atuais.

Ao usar o ShortsBot, o usuário concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.
